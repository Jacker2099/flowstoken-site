登记商户 — 支付相关退款

1. 您购买的内容

FlowsToken 额度为用于在 https://www.flowstoken.com 上支付 AI API 用量的数字预付费服务单位，不是加密货币、证券、储值或现金。一旦 API 调用消耗额度，因上游推理成本已发生，该部分通常无法以现金形式退回。

2. 履约

支付通道确认付款后，平台将对应额度记入您的 FlowsToken 账号，通常数分钟内完成，一般不超过 24 小时。之后您可在控制台创建 API 密钥并使用已发布接口。若订单疑似欺诈、信息不完整、违反条款或需额外核验，可能出现延迟。

3. 退款资格（服务侧 / 未使用额度）

在遵守支付通道（Stripe 或 Waffo）对支付本身适用的规则前提下，平台将在以下情形考虑服务侧退款或未使用额度救济：

  • 购买后 7 日内申请、且无明显 API 消耗的未使用额度
  • 经核实的重复扣款或错误套餐金额
  • 支付已确认但在约定履约窗口内未到账，经调查属实
  • 重大访问故障导致无法使用已购额度，且在合理时间内无法修复

4. 通常不予退款

  • 已通过 API 调用消耗的额度

  • 交付后因共享凭证或未授权第三方使用造成的损失
  • 服务按计量正常运行，但对模型输出不满意
