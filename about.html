关于 FlowsToken

FlowsToken — 智能选模，一个入口。以 Bestoo-Auto 按任务自动选模、按需升级；也可使用普通组与官方组模型。兼容 OpenAI / Anthropic 等风格接口，预付费按量计费——自助注册、充值、创建密钥即可调用。

我们提供什么

用户在控制台完成注册后，可自助充值额度、创建 API Key，并将请求发送至 https://www.flowstoken.com。用量按公开模型价格从预付费余额中扣除。

FlowsToken 不是加密货币、代币发行、钱包或投资产品。额度仅为用于 AI API 推理及相关功能的数字预付费服务单位。
