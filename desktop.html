使用说明

从登录到本地工作流。

Desktop 侧重本地协作体验；模型调用与额度结算仍使用你的 FlowsToken 账户。

01

登录账户 → 一键三组

使用 FlowsToken 账户登录后，可一键切换普通组、智能组（Bestoo-Auto）与官方组。官方组指 GPT / Claude 等厂商官方型号，模型 ID 与厂商一致。

02

文件编辑

在本地项目中阅读与修改文件，把写作、重构与文档整理留在桌面环境，减少在浏览器与编辑器之间来回切换。

03

终端

内置终端方便运行构建、测试与脚本。命令在你的电脑上执行，权限与路径由本机环境决定。

04

浏览器控制

需要时可由助手协助操作浏览器页面。涉及提交表单或支付等敏感动作时，会先请你确认，再继续执行。

05

无插件市场 · MCP 可自配

产品内不提供插件市场。如需扩展能力，可自行配置 MCP；我们会在后续文档中补充推荐接法。
