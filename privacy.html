隐私政策

生效日期：2026年8月31日

本隐私政策说明在使用 FlowsToken 智能选模，一个入口 · 未来的选择 · 预付费按量计费（ https://www.flowstoken.com）过程中，个人信息与账号信息如何被收集、使用与共享。

登记商户（Merchant of Record）

购买 FlowsToken 额度时，由 Waffo Pancake 作为登记商户（在线销售方）处理支付相关数据，并适用其买家条款与隐私声明。平台运营方处理账号与 API 服务相关数据，不在 FlowsToken 服务中存储完整银行卡号。

1. 控制者与角色

平台运营方负责 FlowsToken 服务，是账号注册信息、API 密钥元数据、用量与计量日志、支持沟通记录及提供服务所需相关记录的控制者。

Waffo Pancake 作为额度购买的登记商户，是支付数据的控制者——包括卡或其他支付工具信息、结账所用账单身份、税费/发票记录及支付争议记录——并受 Waffo 买家条款与隐私声明约束。

平台可能从 Waffo 或其处理方接收支付确认与额度到账信息，以便完成履约，但不存储完整支付卡号。

2. 我们收集的信息

账号与服务数据（平台）

  • 注册信息（如邮箱、用户名、可选资料字段）
  • API 密钥（以哈希或同等保护方式存储；密钥标识与备注）
  • 用量记录：模型、Token 数量、时间戳、请求状态，以及在记录范围内的 IP 与 User-Agent
  • 充值/余额台账（金额与状态，不含完整卡数据）
  • 通过邮箱、Telegram、WhatsApp 或控制台渠道的支持消息
  • 安全与风控信号（登录失败、滥用迹象、限流事件等）

支付数据（Waffo）

  • 结账身份、支付方式详情、交易 ID、发票、税费、退款/拒付记录
  • 由 Waffo 作为登记商户按其政策处理

网站遥测

  • 营销/合规页面的标准服务器日志（IP、路径、来源、User-Agent）
  • 我们不出售个人信息

3. 信息用途

  • 提供、保障并改进 FlowsToken API 服务
  • 用户鉴权、用量计量与预付费余额维护
  • 响应支持请求与服务通知
  • 检测欺诈、滥用及违反可接受使用政策的行为
  • 遵守法律并执行服务条款
  • 在需要时与 Waffo 协调支付确认及退款/拒付调查

4. 共享

我们可能与以下方共享信息：

  • Waffo Pancake 及支付处理方，用于结账确认与争议处理
  • 签约的基础设施与安全供应商（托管、日志、邮件投递等）
  • 在法律要求时的专业顾问与主管机关

我们不出售您的个人信息。

5. 保留期限

账号与用量记录在账号有效期间保留，并在之后合理期限内保留，用于安全、会计与合规。支付记录由 Waffo 按其政策保留。您可联系我们申请关闭账号；出于防欺诈或法律要求，部分日志可能继续保留。

6. 安全

我们采用行业通行措施，如传输层 TLS、访问控制与密钥处理实践。任何传输或存储方式都无法保证百分百安全，请妥善保管 API 密钥与密码。

7. 国际用户

FlowsToken 可能从美国以外访问。使用本服务即表示您理解信息可能在美国及我们供应商运营的其他地点处理。

8. 您的选择

  • 在控制台可用处更新账号信息
  • 随时轮换或撤销 API 密钥
  • 联系我们申请查阅、更正或删除（受法律例外约束）
  • 支付数据相关权利请联系作为支付控制者/登记商户的 Waffo，或请我们协助转介

9. 未成年人

FlowsToken 面向成年人与企业用户。我们不会故意收集 16 岁以下（或当地法律要求的更高年龄）未成年人的个人信息。

10. 变更

我们可能通过发布载有新生效日期的修订版更新本政策。重大变更将在本页突出显示，或在适当时通过账号通知告知。
